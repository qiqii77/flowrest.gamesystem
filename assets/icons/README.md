# Open-source icon assets

These SVGs were downloaded from Iconify or the official Lucide repository without changing or drawing their paths.

- Lucide: https://icon-sets.iconify.design/lucide/menu/ — ISC; some inherited icons also include Feather MIT notices. See LUCIDE-LICENSE.txt.
- Simple Icons LINE and Facebook: https://icon-sets.iconify.design/simple-icons/facebook/ — CC0-1.0. See SIMPLE-ICONS-LICENSE.txt.
- SVG Logos Google: https://icon-sets.iconify.design/logos/google-icon/ — CC0-1.0. See LOGOS-LICENSE.txt.

sources.json records every upstream URL and SHA-256 digest. Brand SVG downloads include the upstream API color parameter. Local CSS uses Lucide SVG files as masks so interface colors remain consistent; brand SVGs render as images to preserve their colors.
Brand names and logos remain the property of their respective owners.
